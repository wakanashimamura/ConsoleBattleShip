# ConsoleBattleShip

## Description

**ConsoleBattleShip** is a console-based implementation of the classic **BattleShip** game. The game provides an interactive gameplay experience directly in the Windows console.

![Demo ConsoleBattleShip](https://github.com/wakanashimamura/ConsoleBattleShip/blob/main/ConsoleBattleShip.gif)

## System Requirements

* **Operating System:** Windows only
* The project uses the **Windows API** (`Windows.h`), so it is currently designed specifically for Windows.

## Precompiled Version

A **precompiled version of the game** is already included in the repository, so you can play the game without compiling the source code yourself.

You can find the ready-to-run version in the **`ConsoleBattleShip`** folder.

## Menu Controls

* **Up Arrow / W**: Move cursor to the previous menu item
* **Down Arrow / S**: Move cursor to the next menu item
* **Enter / E**: Select the current menu item
* **Escape / PgUp**: Return to the main menu

## Game Controls

* **Up Arrow / W**: Move the aiming cursor upward or move the ship when placing it on the grid
* **Down Arrow / S**: Move the aiming cursor downward or move the ship when placing it on the grid
* **Left Arrow / A**: Move the aiming cursor to the left or move the ship when placing it on the grid
* **Right Arrow / D**: Move the aiming cursor to the right or move the ship when placing it on the grid
* **Enter / E**: Place the ship on the grid or fire a shot during the game
* **Escape / PgUp**: Return to the main menu
* **Q / PgDn**: Rotate the ship horizontally or vertically

## Features

* Classic BattleShip gameplay
* Interactive console interface
* Keyboard-based controls
* Ship placement system
* Ship rotation
* Aiming and shooting system
* Ready-to-run precompiled version included
* Windows-specific implementation using `Windows.h`
